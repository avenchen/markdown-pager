## 版本 0.2
1. 實作 Markdown rich 顯示功能：
   - 支援 `markdown` 與 `tkhtmlview` 套件進行 HTML 渲染（可選）
   - 若無套件，使用 `ScrolledText` 搭配文字標籤實現基本格式化
   - 支援標題（H1-H3）、粗體、斜體、程式碼區塊
2. 添加字型控制功能：
   - 新增放大（+）與縮小（−）按鈕
   - 字型大小範圍 8-24px，每次調整 2px
3. 移除系統標題列：
   - 使用 `overrideredirect(True)` 移除標題列
   - 新增自訂標題列（可拖動視窗）
   - 添加關閉鈕（✕），滑鼠懸停時變紅
4. 實作透明效果：
   - 視窗整體透明度設為 85%（`attributes("-alpha", 0.85)`）
   - 顯示區背景使用系統顏色，呈現透明效果
5. 允許視窗調整大小：
   - 移除 `resizable(False, False)` 限制
6. 更新所有專案文件以反映新功能。
7. 更新版本資訊至 `0.2`。

## 版本 0.3
1. 移除自訂標題列並整合所有按鈕於工具列，新增「關閉」按鈕。
2. 工具列支援拖動視窗，維持無標題列設計。
3. 新增透明度滑桿，可在 0.5-1.0 間調整視窗透明度。
4. 新增寬度/高度 Spinbox 與「套用尺寸」按鈕，快速設定程式大小。
5. 保持 always-on-top 與 rich Markdown 顯示體驗。
6. 更新 `spec.md`、`version.md` 等文件以記錄新功能。

## 版本 0.4
1. 新增「設定」按鈕，將透明度與視窗大小設定移至彈出視窗：
   - 使用 `Toplevel` 創建設定視窗
   - 設定視窗為模態對話框（`grab_set()`）
   - 透明度滑桿範圍調整為 0.3-1.0，並顯示即時數值
   - 視窗大小設定包含寬度/高度 Spinbox 與「套用」按鈕
2. 實作整個視窗可拖動功能：
   - 綁定整個視窗的 `<Button-1>` 與 `<B1-Motion>` 事件
   - 排除按鈕與控制項的拖動（透過 `isinstance` 檢查）
   - 使用 `event.x_root` 與 `event.y_root` 計算視窗位置
3. 實作設定保存與載入功能：
   - 使用 `json` 模組保存設定至 `config.json`
   - 保存項目：視窗大小、位置、透明度、字型大小
   - 程式啟動時自動載入設定檔
   - 視窗關閉時自動保存設定（`protocol("WM_DELETE_WINDOW")`）
4. 更新所有專案文件以反映新功能。
5. 更新版本資訊至 `0.4`。
